A fast, dependency-free drop-in for csv-reader 1.0.0: `solve.js` reads broken CSV files with exactly the same answers (`{columns, rows, errors}`) — BOM, blank lines, stray CRs, quoted fields, doubled quotes, quote junk, unterminated quotes, short and long rows — but scans with the engine's native `indexOf`/regex search instead of one character at a time, and splits whole quote-free records at once. `main.ts` is the house driver, kept as it ships: it reads every case from `/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
